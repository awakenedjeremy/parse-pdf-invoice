# 发票金额统计器

这是一个用Python开发的电子发票金额统计工具，可以批量统计PDF格式电子发票的金额总和。

## 功能特点

- 支持批量处理PDF格式的电子发票
- 直观的图形用户界面
- 实时显示处理进度
- 显示总金额和处理结果统计

## 安装说明

1. 确保已安装Python 3.6或更高版本
2. 安装所需依赖：
   ```
   pip install -r requirements.txt
   ```

## 使用方法

### 方式一：双击运行（推荐）

直接双击 `运行.bat` 或 `运行.vbs` 即可启动程序，无需打开命令行。

- **运行.bat** — 使用 `pythonw` 后台运行 Python 程序，显示控制台窗口
- **运行.vbs** — 通过 VBScript 调用 `pythonw`，完全静默启动，无控制台窗口

### 方式二：命令行运行

```
python invoice_calculator.py
```

### 操作步骤

1. 启动程序
2. 点击"选择发票文件夹"按钮，选择包含 PDF 发票的文件夹
3. 点击"开始计算"按钮开始处理
4. 等待处理完成，查看统计结果

## 注意事项

- 仅支持PDF格式的电子发票
- 请确保PDF文件可以正常打开和读取
- 程序会自动识别发票中的金额信息
